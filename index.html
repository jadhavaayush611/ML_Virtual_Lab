01 / CONCEPTUAL FOUNDATION

Theory

Understand why dimensionality reduction is useful and how the four techniques represent data.

1. What is dimensionality reduction?

Dimensionality reduction is the process of reducing the number of input variables or features in a dataset while trying to retain the most useful information. It can simplify data, support visualization and reduce computational complexity.

2. The curse of dimensionality

As the number of dimensions increases, data can become sparse and distance-based relationships may become less intuitive. High-dimensional data can also be harder to visualize and analyze.

Feature selection

Selects a subset of the original features.

Feature extraction

Transforms original features into a smaller set of new features.

01

Principal Component Analysis (PCA)

LINEAR

PCA transforms data into a set of orthogonal principal components. The first component captures the greatest possible variance, and each following component captures as much remaining variance as possible.

X → principal components
Useful for compression, visualization and identifying dominant variation.
02

Singular Value Decomposition (SVD)

LINEAR FACTORIZATION

SVD factorizes a matrix into three matrices. Truncated SVD keeps only the largest singular values and their corresponding vectors to form a lower-rank approximation.

A = UΣVᵀ
Useful for compact matrix representations and dimensionality reduction.
03

t-Distributed Stochastic Neighbor Embedding (t-SNE)

NONLINEAR

t-SNE maps high-dimensional points into a lower-dimensional space while emphasizing the preservation of local neighborhood relationships.

High-D → Low-D neighborhoods
Often used to visualize clusters in complex datasets.
04

Uniform Manifold Approximation and Projection (UMAP)

NONLINEAR

UMAP builds a low-dimensional representation using neighborhood relationships and an underlying manifold structure.

Neighborhood graph → embedding
Often used for visualization and exploration of high-dimensional data.

Key observations
  1. Dimensionality reduction represents a dataset using fewer dimensions.
  2. PCA and SVD are linear approaches, while t-SNE and UMAP are nonlinear approaches.
  3. PCA focuses on capturing variance through principal components.
  4. t-SNE and UMAP are commonly used to visualize neighborhood and manifold structure.
  5. Reducing the number of features may simplify a model, but retaining too few dimensions can remove useful information.
