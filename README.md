# Dimensionality Reduction Virtual Lab

Static educational website for Experiment 3: Dimensionality Reduction.

## Required experiment sections
- Aim
- Theory
- Pre-test
- Simulation
- Post-test
- Results
- Conclusion

## Run locally
Open `index.html` in a modern browser. No package installation, backend, API key, or build step is required.

## Deploy on GitHub Pages
1. Create a GitHub repository and upload `index.html`, `styles.css`, and `app.js` to its root.
2. Open Settings → Pages.
3. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Wait for the deployment and open the published Pages URL.

## Simulation note
The simulation is intentionally static. It uses illustrative parameter-driven plots and example metrics; it does not execute PCA, SVD, t-SNE, UMAP, or train a classifier. Do not present illustrative values as measured experimental results.
